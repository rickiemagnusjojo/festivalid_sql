# Festival project / Festivali projekt

Duo project using postgreSQL and DBeaver to create a multi-day festival database with the purpose of making organization of such events easier.

Paaristöö kasutades postgreSQL ja DBeaverit eesmärgiga mitmepäevase festivali jaoks andmebaas teha, mis aitaks taoliste ürituste korraldamist kergemaks teha.
